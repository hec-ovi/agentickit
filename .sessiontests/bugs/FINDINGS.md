# Bugs

Functional regressions and broken paths discovered while exercising the docs. A bug is "the documented or obvious behavior does not work". If it is purely cosmetic, file under `ui-ux/`.

When logging:
- Always include the exact repro (URL, payload, env) so it is reproducible later.
- Capture the failing branch (file path + relevant function) when known.
- Status `fixed-in-<sha>` once a commit closes it; do not delete the entry.
